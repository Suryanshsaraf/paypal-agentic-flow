# paypal-agentic-flow

Autonomous AI agent powered by PayPal's Agent Toolkit & MCP to verify tasks, orchestrate approvals, and execute intelligent payments and payouts.

## What this repo is for

This repository is a submission for the **PayPal AI Hackathon — Build What's Next with PayPal and AI**. It is the home for an application that combines PayPal's developer platform with AI into a single working product.

The goal is an **agentic payment flow**: an AI agent that can understand a request, decide what action to take, and carry out real money movement through PayPal — approvals, payments, and payouts — with the AI driving the decision rather than a human clicking every step.

All PayPal functionality runs against the **free PayPal sandbox** (no real money).

## What is expected

To count as a valid, judgeable submission, the project must:

- **Meaningfully use PayPal.** Integrate at least one PayPal API, SDK, or product (e.g. Agent Toolkit, MCP server, Orders, Payouts), using the sandbox environment.
- **Meaningfully use AI.** AI must be central to the experience — making decisions, reasoning, or driving the flow — not a cosmetic add-on.
- **Be a working prototype.** A real, runnable build that judges can actually use. Mockups and static prototypes do **not** qualify.
- **Be reproducible.** This repo must contain all source code, assets, and setup/run instructions so anyone can build and run it (or reach a hosted demo URL).
- **Be documented.** Clearly explain what it does, how it works, and which AI tools/models were used and how.

### Deliverables checklist

- [ ] Text description of the project's features and functionality
- [ ] Explanation of the AI tool(s)/model(s) used and how
- [ ] Public repository with all code + a visible open-source license (MIT — see [LICENSE](LICENSE))
- [ ] A working demo — clear setup instructions **or** a hosted demo URL
- [ ] A demo video under 3 minutes, public on YouTube, showing the project working
